Privacy and terms

Short version: the game collects nothing, sends nothing, and the source is MIT licensed. The long version is below.

What this site stores

Three values live in your browser's local storage, and nowhere else. They are the theme you picked, whether the win rate bars are shown, and whether shortest paths are drawn on the board. They exist so the page looks the same when you come back. Clearing site data removes them.

What this site collects

Nothing. There is no analytics, no advertising, no tracking pixel, no cookie, and no account. The page makes no network requests to any third party: the typeface is served from this site, and every script is local.

Hosting

This site is served by GitHub Pages. GitHub may keep standard server logs for its own operation, which is outside this project's control. If you would rather not touch a server at all, the same files run from a local folder with no network connection.
